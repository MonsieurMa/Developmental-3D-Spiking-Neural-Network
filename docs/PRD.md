# PRD：BionicBrain —— 全脑结构仿生脉冲神经网络

**版本**：5.0
**日期**：2025
**文档目的**：指导编程 Agent 实现。以人脑解剖结构为骨架，从种子祖细胞发育出全脑分区网络。所有核心机制不得简化。


## 0. 定位声明

**本系统不是 Transformer 的替代品，而是对"脑"本身的计算结构复刻。**

它要回答的问题是：**如果按照人脑的解剖分区、白质连接、发育规则从祖细胞开始生长，会涌现出什么样的计算能力？**

**与果蝇项目的区别**：

| 维度 | 果蝇项目 | BionicBrain |
|------|---------|-------------|
| 连接组来源 | 静态、成体、实测 | 从种子发育、动态、涌现 |
| 规模 | 14 万神经元 | 可配置，10³ – 10⁶ |
| 仿真粒度 | LIF | HH + LIF 混合 |
| 脑区结构 | 果蝇脑 | 人脑全脑分区 |
| 可塑性 | 无 | STDP + 调质 + 发育 |

**与 LLM 的本质差距**（本系统要复刻的）：

1. 异构模块化：视觉、听觉、语言、记忆、情绪、规划是分开的专用子网络
2. 海马是独立记忆硬件：快速记住新事件，不重新全量微调
3. 全局状态调制：情绪、疲劳、唤醒度动态调节所有脑区
4. 异步并行：各脑区并行异步工作，不是 token 串行自回归
5. 内置奖励/价值系统：自带动机，不是被动预测

## 2. 每个区域的祖细胞配置

### 2.1 种子细胞群定义

每个区域都有**独立的祖细胞池**，在发育早期建立。总数按配置：

| 配置 | 区域数 | 每区祖细胞 | 总种子 |
|------|--------|-----------|--------|
| minimal | 30 | 3–5 | 100–150 |
| standard | 30 | 10–20 | 300–600 |
| large | 30 | 50–100 | 1500–3000 |

### 2.2 每区祖细胞类型

每个区域的祖细胞池包含：

| 类型 | 比例 | 功能 |
|------|------|------|
| **区域源点细胞** | 10% | 分泌该区域特有的形态发生素，不分裂，不凋亡 |
| **未分化祖细胞** | 70% | 根据局部形态发生素梯度决定命运 |
| **胶质祖细胞** | 20% | 分化为星形胶质、少突胶质，支持代谢和髓鞘化 |

### 2.3 区域形态发生素

每个区域分泌**至少 1 种区域特异形态发生素**：

| 区域 | 形态发生素 | 扩散系数 | 功能 |
|------|-----------|---------|------|
| 额叶 | M_FRONT | 0.05 | 标记前部身份 |
| 顶叶 | M_PAR | 0.05 | 标记上部身份 |
| 颞叶 | M_TEMP | 0.05 | 标记外侧身份 |
| 枕叶 | M_OCC | 0.05 | 标记后部身份 |
| 丘脑 | M_THAL | 0.06 | 中继站身份 |
| 基底核 | M_BG | 0.04 | 动作选择身份 |
| 小脑 | M_CB | 0.04 | 时序校准身份 |
| 脑干 | M_BS | 0.07 | 生命维持身份 |
| 海马 | M_HIPP | 0.05 | 记忆读写身份 |
| 杏仁核 | M_AMY | 0.05 | 情绪调制身份 |

**全局轴形态发生素**（用于建立前后/背腹/左右轴）：

| 形态发生素 | 来源 | 功能 |
|-----------|------|------|
| M_AP | 额极 + 枕极 | 前后轴 |
| M_DV | 顶叶 + 脑干 | 背腹轴 |
| M_LR | 左半球 + 右半球 | 左右轴 |

### 2.4 相互抑制矩阵

所有区域形态发生素**两两抑制**，形成稳定的区域边界：

```
γ[i][j] = 0.05  (i ≠ j)
γ[i][i] = 0
```

抑制强度根据区域距离调整：相邻区域抑制更强（0.08），远隔区域抑制更弱（0.03）。

## 4. 白质纤维束（通信总线）

### 4.1 主要纤维束

| 纤维束 | 连接 | 延迟 (ms) | 衰减 | 功能 |
|--------|------|----------|------|------|
| **弓状束** | Wern ↔ Broca | 15–25 | 0.9 | 语言通路 |
| **上纵束 SLF** | 额 ↔ 顶 ↔ 颞 | 20–40 | 0.85 | 大范围通信 |
| **下纵束 ILF** | 枕 ↔ 颞 | 20–35 | 0.9 | 视觉→语义 |
| **钩束** | 颞 ↔ 前额 | 25–45 | 0.85 | 概念↔价值 |
| **胼胝体** | 左半球 ↔ 右半球 | 10–20 | 0.95 | 半球互联 |
| **穹窿** | 海马 ↔ 下丘脑 | 15–25 | 0.9 | 记忆通路 |
| **丘脑辐射** | 丘脑 ↔ 各皮层区 | 5–15 | 0.95 | 感觉中继 |
| **皮质脊髓束** | M1 ↔ 脑干 ↔ 脊髓 | 20–40 | 0.9 | 运动输出 |
| **小脑脚** | 小脑 ↔ 脑干 ↔ 丘脑 | 15–30 | 0.9 | 时序校正 |

### 4.2 白质建模规则

每个纤维束不是简单的连接，而是**独立的传输通道**：

- **传输延迟**：与纤维长度成正比，`delay = length / conduction_velocity`
- **信号衰减**：`signal *= attenuation`，每经过一个节点
- **髓鞘化**：活跃纤维束降低延迟、提高传导速度
- **可塑性**：纤维束的传导效率可被调质调节
- **路由**：丘脑作为中央路由器，决定信号送往哪些皮层区

### 4.3 纤维束生长

纤维束不是硬编码的，而是从源点和目标点的祖细胞**生长出来的**：

- 源点祖细胞分泌导向分子
- 目标点祖细胞分泌吸引分子
- 生长锥沿梯度延伸
- 中途遇到其他生长锥时形成**束化**（fasciculation）
- 到达目标后形成突触

## 7. 学习与发育

### 7.1 学习规则

**FR7.1 STDP + 资格痕迹**

- 窗口 ±20ms
- 资格痕迹衰减 ×0.9/步
- 分阶段训练解决多层传播延迟

**FR7.2 多巴胺 RPE**

```
w += DA · DA_gain · eligibility · P(t) · receptor_density
```

**FR7.3 弥散教学**

- 小脑产生教学信号，弥散到运动区和联合区
- 强度随 3D 距离衰减

**FR7.4 突触归一化**

每个神经元输入权重之和 ≤ W_max。

**FR7.5 横向抑制**

区域内部 WTA，区域之间通过丘脑路由。

**FR7.6 禁止反向传播。**

### 7.2 发育规则

**FR7.7 三阶段发育**

| 阶段 | 时间窗 | 主导过程 |
|------|--------|---------|
| 过度生产期 | 0–T_prolif | 大量分裂，区域边界形成 |
| 选择性消除期 | T_prolif–T_prune | 凋亡 + 修剪，纤维束精化 |
| 成熟期 | >T_prune | 仅修剪，纤维束髓鞘化 |

**FR7.8 区域源点细胞不凋亡**

保证形态发生素持续分泌。

**FR7.9 凋亡条件**

- 所有类型可凋亡（除源点细胞）
- `energy < 0.1` 且 `rate < 0.2Hz` 且 `age > 1000ms`

**FR7.10 突触修剪**

- `w < 0.04` 删除
- 每 5000ms 触发突触缩放 ×0.95

**FR7.11 纤维束髓鞘化**

活跃纤维束降低延迟 0.5%/次，最低 5ms。


## 8. 记忆系统（海马）

### 8.1 海马作为独立记忆硬件

海马不是存储权重，而是**动态写入新事件**：

- 输入：当前全脑状态（各区域活动快照）
- 编码：稀疏分布式表征（SDR）
- 存储：情景记忆库（按时间索引）
- 检索：模式补全 + 相似度匹配
- 巩固：睡眠时重放到皮层，写入长期权重

### 8.2 记忆接口

```python
class HippocampusMemory:
    def write(self, brain_state):
        """写入新事件"""
        sdr = self.encode(brain_state)
        self.episodic_buffer.append((time, sdr, brain_state))

    def read(self, query):
        """按相似度检索"""
        sdr = self.encode(query)
        return self.similarity_search(sdr, top_k=5)

    def consolidate(self):
        """睡眠时重放到皮层"""
        for event in self.episodic_buffer[-100:]:
            self.replay_to_cortex(event)
```
