# 海马记忆模块：什么该存、什么不该存、怎么存

你问到了最关键的一点。**海马不是硬盘，不是把所有输入都写进去。** 如果是那样，它就和 RAG 的向量库没区别了。

真实海马是**高度选择性的、压缩的、带索引的、会重放的**。下面分三层讲清楚。

---

## 一、先纠正：不是所有输入都进海马

### 1.1 生物事实

海马通过**内嗅皮层（EC）**接收来自新皮层的输入。但 EC 到海马的投射是**门控的**，不是全量的：

| 输入类型 | 是否进海马 | 原因 |
|---------|-----------|------|
| 重复的、可预测的 | 否 | 习惯化，无新奇性 |
| 新奇的、意外的 | 是 | 需要更新世界模型 |
| 情绪显著的 | 是 | 杏仁核调制，标记重要性 |
| 目标相关的 | 是 | DLPFC 调制，标记相关性 |
| 奖励/惩罚相关的 | 是 | 多巴胺调制，标记价值 |
| 日常琐碎的 | 否 | 无显著特征 |
| 已经巩固的长期记忆 | 否 | 已转移到新皮层 |

**海马是"新奇检测器 + 索引生成器"，不是"全量记录仪"。**

### 1.2 如果全存会怎样

- 记忆库爆炸（每秒几十个词，一年上亿条）
- 检索变慢（相似度搜索 O(N)）
- 无用的重复记忆淹没重要记忆
- 与睡眠巩固机制冲突（重放什么？）

## 二、什么才存：选择性标准

### 2.1 五个编码门槛

只有满足至少一个条件的事件才写入海马：

| 门槛 | 触发条件 | 生物对应 |
|------|---------|---------|
| **新奇性** | 输入与已有记忆的相似度 < 阈值 | 海马对新奇刺激强烈反应 |
| **显著性** | 情绪效价 \|valence\| > 阈值 | 杏仁核调制 |
| **奖励预测误差** | \|RPE\| > 阈值 | 多巴胺调制 |
| **目标相关性** | 与当前 DLPFC 目标向量的相似度 > 阈值 | 前额叶-海马环路 |
| **未完成事件** | 对话未结束、任务未完成 | Zeigarnik 效应 |

### 2.2 新奇性计算

```python
def novelty_score(current_sdr, hippocampus):
    """当前输入与海马中已有记忆的最大相似度"""
    if not hippocampus.episodic_buffer:
        return 1.0  # 空海马，什么都新奇
    max_sim = max(
        cosine_similarity(current_sdr, mem.sdr)
        for mem in hippocampus.episodic_buffer[-100:]  # 只比最近 100 条
    )
    return 1.0 - max_sim  # 相似度越低，新奇性越高
```

**阈值建议**：`novelty > 0.3` 才存。

### 2.3 显著性计算

```python
def salience_score(brain_state):
    """来自杏仁核的情绪标记"""
    amygdala_activity = brain_state.get_region('Amy').mean_rate
    return amygdala_activity / max_rate  # 归一化
```

**阈值建议**：`salience > 0.5` 才存。

### 2.4 目标相关性

```python
def goal_relevance(current_sdr, dlpfc_goal_vector):
    """当前输入与 DLPFC 维持的目标的相关性"""
    return cosine_similarity(current_sdr, dlpfc_goal_vector)
```

**阈值建议**：`relevance > 0.4` 才存。

### 2.5 综合决策

```python
def should_encode(brain_state, current_sdr):
    scores = {
        'novelty':   novelty_score(current_sdr, brain_state.hippocampus),
        'salience':  salience_score(brain_state),
        'rpe':       abs(brain_state.da_level),
        'relevance': goal_relevance(current_sdr, brain_state.dlpfc_goal),
        'unfinished': brain_state.dialogue_state.is_open,
    }
    # 加权求和
    total = (0.4 * scores['novelty'] +
             0.2 * scores['salience'] +
             0.2 * scores['rpe'] +
             0.15 * scores['relevance'] +
             0.05 * scores['unfinished'])
    return total > 0.5, scores
```

## 三、怎么存：存储结构

### 3.1 存的不是词，是事件

**错误做法**：
```python
# ❌ 存原始文本
memory = "你说：你是谁"
```

**正确做法**：
```python
# ✅ 存压缩的事件快照
memory = {
    'timestamp': 12345.6,        # 时间
    'sdr_index': np.array([...]), # 稀疏索引（k=20）
    'context': {
        'regions_active': {...},  # 当时哪些脑区活跃
        'amygdala_valence': -0.2, # 情绪效价
        'da_level': 0.8,          # 多巴胺水平
        'dlpfc_goal': np.array([...]), # 当时的目标向量
    },
    'content_sdr': np.array([...]), # 内容本身的 SDR（来自 Wernicke）
    'motor_sdr': np.array([...]),   # 当时准备输出的 SDR（来自 Broca）
    'consolidated': False,          # 是否已巩固到皮层
}
```

### 3.2 存储的三层结构

```
┌─────────────────────────────────────────────┐
│ L1 情景缓冲区（Episodic Buffer）             │
│ - 最近 N 条事件（比如 1000 条）              │
│ - 快速写入，快速检索                         │
│ - 满后淘汰最旧或最不重要的                    │
├─────────────────────────────────────────────┤
│ L2 情景记忆库（Episodic Store）              │
│ - 长期存储，按时间索引                        │
│ - 睡眠时重放到皮层                            │
│ - 巩固后标记 consolidated=True               │
├─────────────────────────────────────────────┤
│ L3 语义记忆库（Semantic Store，在新皮层）     │
│ - 从情景记忆提炼的抽象知识                    │
│ - 不带时间、地点标签                          │
│ - 分布在海马之外的新皮层区域                  │
└─────────────────────────────────────────────┘
```

### 3.3 为什么用 SDR 而不是词

**SDR（稀疏分布式表征）** 是关键：

- 每个事件用一个 10000 维的稀疏向量表示（k=20 个非零）
- 相似事件有重叠的 SDR
- 海马用**模式分离**（齿状回 DG）让相似事件变得不同
- 海马用**模式补全**（CA3）从部分线索恢复完整记忆

```python
def encode_event_to_sdr(brain_state):
    """把脑状态压缩成稀疏索引"""
    # 1. 从各脑区采样活动
    regions = ['Wern', 'Broca', 'DLPFC', 'Amy', 'Hipp']
    activity = np.concatenate([
        brain_state.get_region(r).activity_vector
        for r in regions
    ])
    # 2. 竞争性稀疏化（k-WTA）
    k = 20
    threshold = np.partition(activity, -k)[-k]
    sdr = (activity >= threshold).astype(int)
    return sdr
```

### 3.4 分词存不存

**不直接存分词。存分词在脑内激活后产生的 SDR。**

流程：

```
输入文本 "你 是 谁"
    ↓ 分词 ['你', '是', '谁']
    ↓ 每个词激活 Wernicke 的 SDR
    ↓ Wernicke 的 SDR 组合成事件表征
    ↓ 海马判断是否值得存
    ↓ 如果值得，存入事件快照
```

**这样存的好处**：

- 不是"存了 '你' '是' '谁' 三个字符串"
- 而是"存了 '你 是 谁' 这个语义模式在脑内的激活状态"
- 检索时能匹配语义相似的事件，不只是字面相同

## 四、检索：怎么取出来

### 4.1 模式补全

给海马一个线索（部分 SDR），它能恢复完整记忆：

```python
def recall(cue_sdr, hippocampus, top_k=5):
    """从部分线索恢复完整记忆"""
    candidates = []
    for mem in hippocampus.episodic_buffer:
        # 模式补全：用线索匹配记忆的 sdr_index
        sim = pattern_completion(cue_sdr, mem.sdr_index)
        candidates.append((sim, mem))
    candidates.sort(reverse=True, key=lambda x: x[0])
    return [mem for _, mem in candidates[:top_k]]
```

### 4.2 检索触发条件

不是每次输入都检索。检索由以下触发：

| 触发 | 场景 |
|------|------|
| **新奇性低** | 输入与已有记忆相似 → 检索相关记忆 |
| **目标相关** | DLPFC 提出查询 → 检索相关记忆 |
| **情绪标记** | 杏仁核激活 → 检索情绪相关记忆 |
| **上下文缺失** | 当前对话不连贯 → 检索上下文 |

### 4.3 检索结果怎么用

检索到的记忆**重新激活对应脑区**：

```python
def reactivate(memory):
    """把记忆内容重新激活到皮层"""
    # 海马的 SDR 作为索引，激活 Wernicke/Broca 的对应模式
    wernicke_pattern = decode_sdr(memory.content_sdr, 'Wern')
    broca_pattern = decode_sdr(memory.motor_sdr, 'Broca')
    # 注入到当前活动
    brain.inject('Wern', wernicke_pattern, strength=0.5)
    brain.inject('Broca', broca_pattern, strength=0.3)
```

## 五、巩固：睡眠时重放

### 5.1 为什么需要巩固

海马容量有限。重要记忆必须**转移**到新皮层，形成长期记忆。这个过程在**慢波睡眠**中发生。

### 5.2 重放机制

```python
def sleep_consolidate(hippocampus, cortex, n_replay=100):
    """睡眠时重放记忆，巩固到皮层"""
    # 1. 选择要巩固的记忆（按重要性排序）
    memories = sorted(
        hippocampus.episodic_buffer,
        key=lambda m: importance_score(m),
        reverse=True
    )[:n_replay]

    # 2. 按时间顺序重放
    for mem in sorted(memories, key=lambda m: m.timestamp):
        # 3. 海马激活对应皮层模式
        reactivate(mem)
        # 4. 皮层-STDP 强化该模式
        cortex.apply_stdp(strength=0.5)
        # 5. 标记已巩固
        mem.consolidated = True

    # 6. 清理已巩固的旧记忆
    hippocampus.episodic_buffer = [
        m for m in hippocampus.episodic_buffer
        if not m.consolidated or m.timestamp > time - 10000
    ]
```

### 5.3 重要性评分

```python
def importance_score(memory):
    return (0.3 * memory.novelty +
            0.3 * abs(memory.amygdala_valence) +
            0.2 * abs(memory.da_level) +
            0.2 * memory.goal_relevance)
```

## 六、完整流程：一次对话的记忆生命周期

```
【第 1 步：输入】
你输入 "你 是 谁"
    ↓ 分词: ['你', '是', '谁']
    ↓ Wernicke 激活 SDR

【第 2 步：EC 门控】
EC 评估：新奇性 = 0.8（第一次见） → 通过
      显著性 = 0.6（语言任务） → 通过
      目标相关 = 0.9（当前在对话） → 通过
    ↓ 决定编码

【第 3 步：海马编码】
DG：模式分离，让这次事件与之前不同
CA3：生成索引 SDR
CA1：与皮层状态绑定
    ↓ 写入情景缓冲区

【第 4 步：响应】
Broca 生成 "我 是 人"
    ↓ 输出
同时海马记录这轮对话的输入和输出

【第 5 步：反馈】
你说 "对"
    ↓ 多巴胺释放
    ↓ 海马中这条记忆的 da_level 更新为 +1.0
    ↓ 突触强化

【第 6 步：再输入】
你又说 "你 是 谁"
    ↓ Wernicke 激活相似 SDR
    ↓ EC 评估：新奇性 = 0.1（已见过） → 不通过
    ↓ 但触发检索
    ↓ 海马返回上次这条记忆
    ↓ 重新激活 Wernicke 和 Broca
    ↓ 输出 "我 是 人"（更强化）

【第 7 步：睡眠】
网络进入睡眠模式
    ↓ 重放最近重要记忆
    ↓ "你 是 谁" → "我 是 人" 巩固到皮层
    ↓ 海马中该记忆标记 consolidated=True
    ↓ 下次再问，不经过海马也能直接回答

【第 8 步：长期】
几轮后，"你 是 谁" → "我 是 人" 变成语义记忆
    ↓ 海马不再存储这条
    ↓ 新皮层直接处理
    ↓ 海马腾出空间给新事件
```

## 七、加入 PRD 的模块定义

### FR11：海马记忆模块

**FR11.1** 海马不是全量存储器。只有满足以下至少一个条件的事件才被编码：

- 新奇性 > 0.3
- 显著性 > 0.5
- |RPE| > 0.3
- 目标相关性 > 0.4
- 事件未完成

**FR11.2** 编码的对象不是原始文本，是**事件快照**：

- 时间戳
- 稀疏索引 SDR（k=20）
- 内容 SDR（来自 Wernicke）
- 运动 SDR（来自 Broca）
- 情绪效价（来自杏仁核）
- 多巴胺水平
- DLPFC 目标向量
- 各脑区活跃度

**FR11.3** 存储三层：

- 情景缓冲区：最近 1000 条，快速读写
- 情景记忆库：长期，按时间索引
- 语义记忆库：在新皮层，从情景提炼

**FR11.4** 检索机制：

- 模式补全（CA3）
- 相似度匹配
- 触发条件：新奇性低 / 目标相关 / 情绪标记 / 上下文缺失

**FR11.5** 巩固机制：

- 睡眠时重放
- 按重要性排序
- 重放到皮层，STDP 强化
- 巩固后清理海马

**FR11.6** 重要性评分：

```
importance = 0.3·novelty + 0.3·|valence| + 0.2·|DA| + 0.2·relevance
```

**FR11.7** 海马容量上限：可配置，默认 10000 条。超限时淘汰最不重要的已巩固记忆。

## 八、一句话回答你的问题

| 你的问题 | 答案 |
|---------|------|
| 所有输入都存吗？ | **不。只有新奇的、显著的、目标相关的、情绪标记的才存** |
| 存分词吗？ | **不存分词字符串，存分词在脑内激活后产生的 SDR** |
| 怎么存？ | **事件快照：时间 + SDR 索引 + 脑区状态 + 情绪 + 多巴胺** |
| 什么样的才存？ | **满足五个门槛中至少一个的** |
| 存了之后呢？ | **睡眠时重放到皮层，巩固后从海马清除** |
| 怎么取？ | **模式补全 + 相似度匹配，触发条件不是每次输入** |

**核心原则**：海马是**索引**，不是**仓库**。真正的记忆内容分布在新皮层，海马只存"指向哪里"的指针。这和 RAG 的向量库有本质区别——RAG 存全文，海马存索引。
