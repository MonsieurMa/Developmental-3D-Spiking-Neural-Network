# 智能涌现设计（Emergence by Design）

更新时间：2026-09-18
状态：设计约束 + 已实现机制清单。本文档定义"什么算涌现"、"结构上必须具备什么"、"当前实现到哪一步"。

## 1. 立场：涌现不是训练量的问题

本项目的硬约束（`AGENTS.md`）：不用 MLP、反向传播、Transformer、静态答案查表、预设完整连接组；输入必须过感觉/丘脑路由，输出必须走运动群体解码，学习必须局部且受生物约束。

在这个约束下，智能涌现不能靠"喂更多 QA 对"。它需要**结构**：一个能自己产生学习信号、能把经验压缩成可复用结构、能在新情境里重新组合的回路。QA 训练只是其中一种输入，而且是信息量最低的一种（它替网络完成了"该学什么"的判断）。

## 2. 涌现的工作定义（可测量）

把"涌现"拆成六条可测判据，全部由 `tools/emergence_report.py` 自动打分：

**所有判分都由本地大模型（`LlmTeacherAgent.judge`）按语义给出，不用字符精确匹配。** 网络输出的是 token 列表，"地 湿"与"地湿"、"thank you"与"谢谢"是同一个答案。报告里会记录判分模型（`model@base_url`）与离线退化次数；token 级指标只作为辅助（命名带 `_aux`），不作为分数。

| 判据 | 含义 | 测量方式 |
|---|---|---|
| E1 保持 | 学会的东西在大量新经验后仍然记得 | 教 N 条 → 插入 M 条干扰 → 复测 |
| E2 皮层回忆 | 不依赖海马指针，皮层关联能独立召回 | 禁用 `hippocampus.retrieve` 后复测 |
| E3 改写泛化 | 同一含义的不同说法能召回 | 改写句相似度 ≥ 阈值 |
| E4 组合泛化 | 把新填充项代入已学框架并正确作答 | 零样本槽位题（新名字/新物体） |
| E5 跨模态迁移 | 通过"听"学会的内容，用"看"也能答（反之亦然） | 听觉流学习 → 视觉提问 |
| E6 自监督进步 | 阅读/听讲时自己的预测误差持续下降 | 流式 surprise 曲线斜率 |

再加两条"生成"指标：E7 续写长度、E8 重复率（越低越好）。

任何声称"涌现了"的说法，必须给出这八项的前后数字，否则不算。

## 2.1 判据协议（怎么判断"涌现"而不是"碰巧"）

单看正确率无法区分三件事：网络真的学会了、机制本身带来的、还是碰巧答对。所以每条判据都要跑**三种对照**，且题目必须先验证"模型没见过"：

1. **未见性检查**：题目字符串不得出现在任何语料里（`tools/generalization_probe.py` 自动查重，命中会标记 `seen_in_corpora`）。
2. **机制消融**（`--ablate-schema`）：关掉绑定/关联读出，看分数掉多少。掉到 0 才说明是这个机制在起作用。
3. **未训练基线**（`--untrained`）：全新脑跑同一套题，区分"先天结构能力"和"学到的能力"。
4. 判分一律由本地大模型按语义给出（`LlmTeacherAgent.judge`），不用字符串相等。

判据按来源分两类：

| 类别 | 判据 | 含义 | 判据成立条件 |
|---|---|---|---|
| 先天脚手架 | G2 一次性绑定 / G4 组合绑定 | 读一次就能答、新填充项代入框架 | 未训练脑也能过，且**消融后掉到 0** |
| 学到的能力 | G5 跨模态、L1 保持、L2 巩固问答、L3 长文续写、G6 校准 | 需要训练才能获得 | **未训练脑明显更低** |

三条"训练缺口"证据（2026-09-19，通用模型 vs 全新脑 vs 消融）：

| 判据 | 通用模型 | 消融机制 | 未训练脑 | 结论 |
|---|---|---|---|---|
| G3 改写召回 | 1.00 | 1.00 | 1.00（当场教过） | 关联能力，非本机制 |
| G2 一次性事实 | **1.00** | **0.00** | 1.00（当场读入） | 脚手架机制，消融可证因果 |
| G4 角色组合 | **1.00** | **0.00** | 1.00（当场读入） | 同上 |
| G6 未知词校准 | **1.00（拒绝）** | 1.00 | **0.00（瞎编）** | **必须训练**才能学会"不知道就说不知道" |
| L2 巩固问答（13 题，不重教） | 13/13 | — | 0/13 | 必须训练 |
| L3 长文续写 | 46 token 后自停 | — | 0 token | 必须训练 |

**解读规则**：判据说"涌现"，要求同时满足（a）题目未见、（b）分数显著高于机制消融基线、（c）至少一条"训练缺口"证据存在。只满足（a）（b）的是**结构能力**，不是涌现；只满足（c）而无对照的是**训练痕迹**。真正的信号是两者叠加：结构提供容量，学习填满并校准它——未训练脑会瞎编、训练后知道该闭嘴，就是这种叠加的直接证据。

## 3. 必须具备的五种结构

### 3.1 自监督预测学习（不依赖答案文本）

人类读书时没有 QA 标签：一边读一边预测下一个词，预测错了就更新。

- 网络用自己的转移先验 + 运动群体解码给出预测；
- 真实的下一个 token 到达时计算 surprise（`SequentialPredictor.surprise`）；
- surprise 与预测正确与否转成多巴胺/可塑性增益，调制**局部 Hebbian**（上下文 → 实际 token 的运动/语义装配），而不是外部灌入的答案；
- 可预测的片段学习率低（已经会了），意外片段学习率高（信息量大）。这正是"惊讶驱动学习"。

实现：`BionicBrain.observe_stream()`，配合 `IntrinsicDrive`。

### 3.2 多模态汇聚（看、听、触共用语义枢纽）

所有模态最终汇聚到同一个语义枢纽（Wern 区）。外围皮层（V1/A1/S1）保留模态特有表征，模态之间通过枢纽形成迁移——听过的词，看到也能懂。

- `WordBinding.sensory` = 语义枢纽装配（模态无关）；
- `WordBinding.channels` = 各模态外围装配（V1/A1/S1），每个模态首次出现时发育，并用局部关联投到枢纽；
- `perceive(text, modality)` / `listen()` / `read()` 把经验送进来；`answer(question, modality)` 从任一通道提问。

### 3.3 角色-填充绑定（组合泛化的核心）

把"把…给…""在…""是…"这类框架抽成**角色槽位**，把具体人名/物体作为**可替换填充**绑定在工作记忆里（前额叶结合编码），而不是为每个实例存一条问答。

- 框架从阅读中统计得到（角色标记 + 角色词分布）；
- 提问时判断问的是哪个角色（"谁 有 X" 问持有者）；
- 把当前情境中绑定到该角色的填充项激活（covert rehearsal），再由运动群体解码输出。
- 关键：填充项来自**当前正在感知的情境**，不是记忆里的答案表，因此这是变量绑定而非查表。

实现：`memory/schemas.py`。

### 3.4 内在动机（自己决定学什么）

没有好奇心，网络永远只会学被喂的东西。内在奖励由三部分构成：

`curiosity = w_novelty·novelty + w_surprise·surprise + w_progress·(surprise_下降量)`

它决定：什么进入海马、睡眠重放谁、下一个注意目标是谁。实现：`modulation/drives.py`，被 `observe_stream()`、`sleep()`、`should_encode()` 使用。

### 3.5 巩固与重放（把情景变成结构）

海马存情景索引，睡眠重放把反复出现的模式巩固成皮层关联；巩固后情景仍然可检索（本轮已修）。重放顺序由重要性 + 好奇心决定，而不是按时间顺序。

## 4. 与"QA 训练"的关系

训练输入应当是混合的，且互相补足：

| 输入形式 | 提供的东西 | 实现 |
|---|---|---|
| 阅读（书籍/文章流） | 语言的统计结构、常识、世界知识的分布 | `read()` / `observe_stream()` |
| 听讲（带时序的语音流） | 时序整合、韵律切分、听觉通道表征 | `listen()` / `observe_stream(modality="auditory")` |
| 对话/QA | 纠错信号、目标导向的映射 | `learn_pair()` + `correct()` |
| 观察/操作 | 具身因果、动作-结果关联 | `learn_narrative()` + 运动输出 |
| 睡眠重放 | 巩固、抽象、去噪 | `sleep()` |

QA 只负责"纠正"，不负责"知识来源"。知识主要来自阅读/听讲/观察，这是本项目要转向的训练范式。

## 5. 反模式（明确禁止）

- 把长答案整串当短语回放当作"生成长文本"；
- 用符号模型直接返回答案（`inspect_*_symbolic` 只能做离线诊断）；
- 用问答字典/查表提高分数；
- 为了指标放宽门槛到"什么都答"；
- 把整段文本一次性灌成一条记忆（那是压缩存储，不是学习）。

下一阶段的重点不是再加机制，而是**用混合流训练并让 E1–E8 一起上升**：

1. 用 `read()` 灌入长文本（书籍语料，无 QA）；
2. 用 `listen()` 灌入同一内容的听觉流，测 E5；
3. 用 `learn_pair()` 做少量纠错；
4. 每轮用 `sleep()` 巩固，用 `emergence_report.py` 打分，只保留总分上升的检查点。
